# KruigerDV

A simple standalone FiveM vehicle deletion script that allows players to quickly delete their current or nearby vehicle using `/dv`.

## Features

- Delete the vehicle you are currently in
- Delete the nearest vehicle when on foot
- Configurable command
- Configurable nearby vehicle distance
- Standalone
- No framework required
- No dependencies

## Installation

1. Download `KruigerDV`.
2. Place `kruiger_dv` in your server's `resources` folder.
3. Add `ensure kruiger_dv` to your `server.cfg`.
4. Restart your server.

## Usage

Use `/dv` in-game.

## Configuration

Edit `config.lua` to change the command, maximum nearby vehicle distance, or disable deleting nearby vehicles.
